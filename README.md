# Ерөнхий зааварчилгаа

Бидний зорилго бол төслийн талбай дахь нийт ажилчид, эд хөрөнгийн аюулгүй байдлыг дээд зэргээр хангаж, болзошгүй аливаа эрсдэлийг хяналтанд авснаар төслийн ажлыг ямар нэгэн осолгүйгээр гүйцэтгэх явдал юм.

Төслийн талбайн аюулгүй ажиллагааны ерөнхий дүрэм:

1\) Төслийн ажлын талбайд нийт ажилчид хамгаалалтын малгай, хамгаалалтын хувцасыг тогтмол хэрэглэнэ.

-Нэг бүрийн хамгаалах хэрэгсэл гэж үйлдвэрлэлийгн хортой, аюултай хүчин зүйлийн нөлөөллөөс ажилтны амь нас, эрүүл мэндийг хамгаалах зориулалт бүхий стандартад нийцсэн доорх хэрэгслүүдийг хэрэглэнэ. Үүнд:

-Хамгаалалтын болон гэрэл ойлгогч бүхий хувцас

-Толгой хамгаалах хэрэгсэл

-Нүд хамгаалах хэрэгсэл

-Хөл хамгаалах хэрэгсэл

-Гар хамгаалах хэрэгсэл багтай.

Дараах өнгөний кодоор ялгагдана.

Ажлын тусгай хувцасны бүрдэл материал нь стандартын шаардлага хангасан, ажилтанд ажиллахад саад болохгүй байхаар хийгдэнэ.

Ажлын талбарт ямар нэгэн ажил гүйцэтгэхдээ аюулгүй ажиллагааны дүрмээр заавал биелүүлэх, аюулгүй тэмдэг тэмдэглэгээгээр заагдсан нэг бүрийн хамгаалах хэрэгслийг заавал хэрэглэнэ.

2\) Хамгаалалтын шилийг ажлын талбайд тогтмол хэрэглэнэ.

3\) Дуу чимээ стандарт хэмжээнээс ихтэй ажлын байранд болон түүний ойр орчимд чихний бөглөөг тогтмол хэрэглэнэ

4\) Гагнуур, таслах болон бусад эсрдэлтэй ажлуудад зориулалтын бээлийг тогтмол хэрэглэнэ.

5\) Өндрөөс унах аюултай ажлын байранд өндрийн бүсийг тогтмол хэрэглэнэ.

6\) Төслийн нийт талбайд хамгаалалтын ажлын гуталтай ажиллана.

7\) Төслийн талбайд согтууруулах ундаа (Удирдлагаас албан ёсоор зөвшөөрсөн албан ёсны арга хэмжээнээс бусад бүх тохиолдолд), мансууруулах бодис, сэтгэцэд нөлөөлөх эмний хэрэглээг хориглоно.

8\) Гал сөнөөх зориулалттай багаж тоног төхөөрөмж, хорыг зөвшөөрөлгүйгээр хөдөлгөх, байрлалыг өөрчлөхийг хориглоно.

9\) Анхааруулах тэмдэг тэмдэглэгээг дагаж мөрдөнө.

10\) Аюултай тохиолдол бүрийг өөрийн ахлах ажилтан болон ЭМААБО хариуцсан ажилтанд мэдэгдэнэ.

11\) Зөвхөн зааварчилгааны дагуу ажиллах ба эргэлзээтэй нөхцөл байдалд өөрийн ахлах ажилтнаасаа асууна.

12\) Гар болон суурин цахилгаан багажийг ямагт газардуулгатайгаар хэрэглэнэ.

13\) Ил задгай хог хаягдал хаяхыг хориглоно.

14\) Зөвхөн зөвшөөрөгдсөн орц гарцаар ажлын байранд нэвтэрч эсвэл орхино.

15\) Ажлын байрны эмх цэгцийг үргэлж хангаж ажиллана.

16\) Гэмтсэн тохиолдол бүрийг өөрийн ахлах ажилтан болон ЭМААБО ажилтанд мэдэгдэнэ.

17\) Орохыг хориглосон ажлын талбайд зөвшөөрөлгүйгээр нэвтрэхийг хориглоно.

18\) Аюулгүй ажиллагааны дүрэм, журам, заавар зааварчилгааг дагаж мөрдөнө.
